Ami – Personal AI Companion

Full-Stack AI Companion Platform with Voice Messaging, Long-Term Memory & Cross-Site Session Architecture

Project Overview

Most contemporary AI conversational tools are built as disposable, transactional prompt boxes—resetting context with every fresh session and lacking any emotional attunement or voice interaction. Ami was engineered to solve this by providing a warm, persistent personal AI companion. The platform pairs deep conversational reasoning via Google Gemini with permanent relational memory in PostgreSQL, dynamic user-consent-driven context injection, dual-mode voice interaction (speech-to-text and neural text-to-speech), and a resilient, optimistic chat interface.

System Architecture

React 19 / Vite
Vercel Edge Deployment
Django REST API
Gunicorn on Render
PostgreSQL
Neon Serverless (SSL)
AI Engine: Django communicates with Google Gemini API for natural reasoning and audio speech-to-text.
Speech Synthesis: Voice responses generated via configured Microsoft Edge TTS (neural voice stream).

Key Engineering Work

Backend API Architecture

Django 4.2+ REST Framework backend engineered with domain modularity: chat messaging, conversation management, memory retrieval, and diagnostics.

Authentication & Session Management

Robust session-based authentication with cross-origin cookie security, CSRF token issuance, and protected user conversation isolation.

Database Persistence

PostgreSQL schema utilizing UUID primary keys, composite indexing (user/time), message ordering, and persistent mood state models.

Memory Retrieval & Context Injection

Categorized memory system (preferences, personal facts, work) with importance ranking and user-approval consent gates injected into the LLM system prompt.

Voice Message Pipeline

Client-side MediaRecorder audio recording, multipart audio upload, Gemini audio transcription (STT), and neural voice playback with inline scrubbing.

Optimistic UI & Failure Recovery

Real-time-feeling chat UI with instant optimistic message rendering, sending spinners, client/server ID reconciliation, and manual retry triggers.

Engineering Challenges & Solutions

Challenge

Cross-Origin Session Cookies in Production

Modern browsers enforce strict third-party cookie restrictions when the React frontend (Vercel) communicates with an external Django backend (Render).

Solution

Configured SESSION_COOKIE_SAMESITE = 'None' and SESSION_COOKIE_SECURE = True, paired with explicit CORS_ALLOW_CREDENTIALS and client-side credentials: 'include'.

Challenge

CORS & CSRF Protection for SPAs

Standard Django CSRF protection blocked cross-origin mutation requests (POST/PUT/DELETE) originating from the decoupled Single-Page Application.

Solution

Established a dedicated /api/auth/csrf/ endpoint and dynamic client-side X-CSRFToken header injection for state-modifying API calls.

Challenge

Optimistic Message Reconciliation

Rendering messages immediately prior to server acknowledgment caused UI duplication or jumping when backend UUIDs replaced temporary client IDs.

Solution

Designed an immutable message reconciliation pipeline in React that cleanly matches client timestamps and IDs, eliminating screen flicker.

Challenge

Serverless PostgreSQL Connection Scaling

Neon PostgreSQL serverless compute nodes suspend when idle and drop persistent connection pools under sudden request spikes.

Solution

Integrated dj-database-url with enforced SSL connection parameters and balanced connection lifetimes (conn_max_age) for resilience.

KIFA FoodCo Management System

Full-Stack Wholesale Bakery Operations & Logistics Distribution Platform

Project Overview

A comprehensive, production-grade business management platform developed and deployed for KIFA FoodCo, a wholesale bakery manufacturing and multi-vehicle distribution enterprise. The system replaces fragmented manual records with an automated, synchronized workflow spanning godown stock control, dynamic delivery routes, shop ledger bookkeeping, and end-of-trip settlement.

Key Operational Modules

Inventory & Stock Management

Real-time stock counts across production batches, units, and godown reserve levels with automated low-stock warnings.

Product Batches & Godown Control

FIFO batch management, manufacture/expiry tracking, and synchronized warehouse dispatch allocations.

Delivery Trips, Vehicles & Drivers

Daily distribution run dispatching, vehicle fleet assignments, driver/sales staff load sheets, and trip reconciliation.

Shop Ledger & Balance Tracking

Individual retail store directories with automated outstanding balance ledgers, transaction history, and credit terms.

Sales, Invoices & Payment Tracking

Fast point-of-delivery invoice generation, cash/UPI payment collection logs, and outstanding balance settlement.

Purchases & Supplier Management

Supplier directory, raw material replenishment orders, cost logging, and payables ledger tracking.

Returns Management

Return item processing from retail routes, credit note generation, and godown inventory adjustments.

Admin Dashboard & RBAC

Role-based authentication guarding administrative functions, dispatch crew views, and revenue analytics.

Architecture & Tech Stack

Frontend Architecture

React, TypeScript, Tailwind CSS, Vite, Service Worker PWA support, Responsive mobile-first interface

Backend & API Services

Node.js, Express.js REST API architecture, JWT authentication, CORS, robust endpoint validations

Relational Database

PostgreSQL via Neon Serverless, connection pooling, relational schemas & indexed queries

Deployment & Cloud Infrastructure

Cloudflare Pages (Frontend edge CDN) and Render (Node.js web service)
